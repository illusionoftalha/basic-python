PYTHON: A SHORT INTRODUCTION

Python is a general-purpose programming language created by Guido van Rossum.
It is used for automation, web services, data analysis, scientific computing,
education and many other tasks. Its readable syntax helps beginners focus on
programming ideas, but Python is not the only language with readable syntax.

THIS COURSE

Use Python 3.10 or newer. From the repository root, start with:
    python -m lessons.beginner.variables

Follow docs/LEARNING_PATH.md for the ordered course. The original index.py and
advanced.py files preserve early notes; many examples there are commented out.

HOW PROGRAMS RUN

A Python implementation reads and executes your program. CPython compiles source
into bytecode and executes that bytecode in its interpreter. You normally run a
.py file without a separate manual compilation step. Other implementations can
use different execution strategies.

Python supports procedural, object-oriented and functional styles. It uses
indentation to group statements. Names refer to objects, and objects have types.
input() returns text; convert and validate that text before using it as a number.
